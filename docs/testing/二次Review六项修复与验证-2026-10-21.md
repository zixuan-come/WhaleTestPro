## 影响与边界

这六项修复不新增数据库迁移，不清空用户、项目、接口、用例或报告数据；接口/用例树及报告目录结构保留。公共执行 API 的可选 `env_id` 协议保持兼容，本轮在页面执行入口要求有效选择；直接 API 调用者仍需自行提供适用的环境和请求地址。

首次应用动态 DNS 配置需要重建 frontend。Docker 外部署需配置实际可用的 DNS 和后端地址，详见[部署说明](../deployment.md)。后端替换及 DNS 缓存切换窗口内仍可能短暂失败，应继续使用健康检查重试。

上述验证在提交前完成，不代表已完成云端部署验收或真实 WhaleShop 性能验收。验证时用户已确认云端仍是此前版本；部署状态应以实际服务器版本为准。
