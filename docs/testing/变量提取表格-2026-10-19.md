# 变量提取表格（2026-10-19）

接口用例高级配置、场景步骤和压测步骤共用“变量名 / 提取表达式 / 提取结果”表格。填写 `order_id` 和 `$.id` 后，后续请求使用 `${order_id}`。支持添加和删除行，旧映射自动回填，保存仍使用原有 API 字段，无数据库迁移。

场景单步发送后，点击“验证提取”在同一行显示值或错误；验证读取缓存响应，不重新发送业务请求。修改名称或表达式后不沿用旧行结果；修改请求后隐藏旧提取结果并要求重新发送。接口用例和压测配置入口显示“运行时提取”，不伪造未执行结果。

重复变量名、缺少名称或表达式的行会阻止保存/验证；全空行忽略，删除全部规则可清空配置。场景调试和压测分别沿用后端已有的数量、长度与保留变量限制。JSONPath 语法仍由已有执行服务校验，保留 `data.token` 等旧表达式。

临时调试变量及报告中的提取变量也改为只读表格；历史报告没有表达式的，不补造表达式。布尔值、0、null、空数组和对象保留原类型展示，敏感值继续使用服务端脱敏结果。

本次只修改前端及说明。验证范围为前端组件/保存配置测试、生产构建，以及 gstack 浏览器中的实际 Vue 页面与模拟 API；不执行接口回归或真实压测。

验证结果：前端全量 157 项通过；最后补充的整体错误提示及长结果样式经 23 项相关测试和 Docker 生产构建通过。gstack 验证旧规则回填、增删与编辑、重复名称阻止保存、场景提取不重发请求、临时变量复用，以及明暗主题和 390px 窄屏，无控制台错误。本地 frontend 镜像和容器已更新。
