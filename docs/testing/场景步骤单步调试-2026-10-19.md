# 场景步骤单步调试（2026-10-19）

步骤行新增“调试”，在既有编辑窗口发送当前草稿。结果展示实际状态码、耗时、响应体/响应头及实际请求，状态或断言失败仍展示响应。复制响应兼容 HTTP 部署。请求与证据复用原执行及脱敏逻辑，不通过新增/修改接口或用例来间接调试。

## 使用

1. 在场景顶部选环境，点击“创建订单”步骤的“调试”，填写草稿后点“发送请求”。
2. 查看 JSON，在变量提取表格中填写变量名 `order_id`、提取表达式 `$.id`，点“验证提取”，在同一行查看结果。验证只读缓存响应，不再次创建订单。
3. 点击“应用到当前步骤”，保存场景；再调试查询步骤，它会使用同会话提取的 `${order_id}`。
4. 缺失变量时不发送业务请求，可在提示中填入临时值，或先调试前置步骤。请求字段改变时，上次响应会标明过期用途并禁用提取验证；重新发送后恢复。

调试变量与配置保存独立。取消编辑不修改步骤配置；已提取变量继续供本次调试使用。切换用户、项目、场景、环境会立即清理变量、结果及打开的窗口，晚到响应不恢复旧上下文。刷新或清空后建立新会话，旧缓存按 TTL 到期删除。

## 后端契约

- `POST /scenarios/{scenario_id}/debug?env_id=1`，请求 `{step, session_id?, variables?}`。step 使用既有独立快照校验；临时变量仅作本次调试输入，不能覆盖环境 base_url。
- `POST /scenarios/{scenario_id}/debug/extract?env_id=1`，请求 `{session_id, response_id, extract_rules}`。返回提取逐项结果、脱敏变量及当前缓存证据，不触发 HTTP。
- 两接口均要求项目内场景执行权限，来源和接口按原有副本授权规则验证。会话/响应票据不能跨用户、项目、场景、环境或主/影子库使用；过期或忙碌返回 409，Redis 不可用返回不含连接凭证的 503。
- Redis 会话采用锁防止并发覆盖，空闲 TTL 为 600 秒；最多缓存 8 次 JSON、会话约 1 MiB，变量最多 100 项/128 KiB。正文大于 256 KiB 或非 JSON 时仍可查看截取证据，但不提供提取票据。
- 原始 JSON 和敏感变量只保留在受限的临时缓存中；页面与返回证据均脱敏。后续请求使用服务端原值，JSONPath 验证原子更新当前步骤变量，移除的旧规则不残留。重新发送生产变量的步骤会先清理该步骤旧变量，避免复用旧订单号。
- 单步执行不写场景、接口、用例及正式报告，不执行前后置 SQL、数据集或重试。断言行为与既有链路一致。

## 验证

隔离后端测试涵盖草稿执行、响应保留、提取不重发、类型保留、凭证脱敏和复用、缺失变量、来源/环境/用户/场景隔离、过期、Redis 故障、网络超时、超限与非 JSON、修正规则后的结果更新。前端测试覆盖草稿不落库、缓存票据、重复点击、失效响应、取消和上下文切换。

gstack 浏览器使用实际 Vue 页面和模拟 API，验证创建、JSONPath 提取、查询复用、清空变量，以及明暗主题和窄屏。以上不代表已对云端或 WhaleShop 执行真实测试。

最终验证：后端离线 634 passed、10 条条件跳过；前端 150 passed，生产构建通过。本地 app/frontend 已更新，就绪检查中的两库、Redis、RabbitMQ 均为 ok；实际 OpenAPI 为 109 项，新接口与前端资源均已提供。实际本地 Redis 验证通过锁、序列化、600 秒 TTL 和用户隔离，临时测试键已清理，没有发送真实订单请求。

此改动新增 2 项 HTTP 操作，平台接口总数由 107 增至 109。无需数据库结构迁移，但部署时必须同时更新 app 和 frontend；只更新前端无法提供新调试接口。
