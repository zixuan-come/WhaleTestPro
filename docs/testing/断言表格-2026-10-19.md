# 断言表格（2026-10-19）

接口用例、场景步骤、压测步骤的断言配置统一为“断言对象 / 字段或表达式 / 判断条件 / 期望值 / 实际值与结果”。支持逐行添加、删除；状态码仍使用现有“期望状态码”。高级配置维持默认收起。

- 响应 JSON 支持等于、包含、大于、小于；响应头支持等于、包含；响应时间按毫秒比较。
- 期望值显式区分文本、数字、布尔、null、JSON，保留空字符串、0、false、对象和数组。选择 JSON 时展开编辑区域。
- JSON Schema 和数据库只读 SELECT 展开专用区域。压测沿用已有 HTTP 断言范围，不提供数据库断言。
- 旧断言自动回填，保留旧字段和期望值类型；未知旧类型保留原配置供修改或删除，不能静默丢弃。删除全部行会清空断言；不完整字段或无效数字、JSON 阻止保存。
- 场景单步与接口用例运行后显示实际结果，逐行匹配执行时的配置。断言改变后不沿用旧行结果；用例请求或环境改变后也不沿用旧结果。场景期望状态码或断言改变时提示重新发送更新校验结果。
- 用例结果、场景结果和报告改用只读结果表。历史记录没有 JSONPath/SQL 的显示“—”，不根据当前配置补造历史证据。

保存仍使用既有 assertions 数组，未修改后端契约，无数据库迁移。断言编辑不会自行发送请求；压测配置只显示“待执行”，不虚构无法获得的逐条运行值。

验证：前端全量 166 项测试通过，生产构建通过。gstack 浏览器使用实际 Vue 页面与模拟 API，覆盖旧规则回填、文本与数字区分、SQL/Schema 保存、场景执行与旧结果失效、压测编辑、报告展示、明暗主题和 390px 窄屏，无控制台错误。按用户要求未执行接口回归或真实压测。
