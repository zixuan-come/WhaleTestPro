## 3. 技术栈与运行方式

- 后端：FastAPI + SQLAlchemy
- 前端：Vue 3 + Pinia + Vue Router + Vite
- 数据库：MySQL（主库 + 影子库）
- 缓存与黑名单：Redis
- 异步任务：Celery + RabbitMQ；定时任务由 Celery Beat/RedBeat 触发
- 压测：Locust master/worker
- 监控：Prometheus + Grafana
- 部署：Docker Compose；前端生产产物由 Nginx 托管并将 `/api` 反向代理到后端

后端分层约定：

```text
router -> service -> repository -> model
                    schema 负责请求/响应数据模型
```

主要目录：`app/core`、`app/models`、`app/schemas`、`app/repositories`、`app/services`、`app/routers`、`app/tasks`、`frontend`、`tests`、`docker`、`docs`。

Compose 中包含 app、frontend、mysql、redis、rabbitmq、worker、prometheus、grafana、locust-master 和 locust-worker 等服务。MySQL 首次启动会创建影子库；已有数据卷不会重复执行初始化脚本。

### 4.4 统一 API 响应

业务 API 通常返回：

```json
{
  "code": 0,
  "message": "操作成功",
  "data": {}
}
```

成功固定 `code=0`；失败通常使用 HTTP 状态码作为 `code`。参数校验、HTTPException 和未处理异常由全局异常处理器包装。Mock 命中、Prometheus、Swagger、静态资源等特殊协议不强制套 envelope。详细规则见 `docs/api-response.md`。
