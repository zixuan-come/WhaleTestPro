## 2. 背景与目标
项目是平台的数据隔离根。用户在选中的项目上下文中管理环境、接口、用例、场景、报告、Mock、回归、调度、性能和流量资产；成员角色决定项目和成员管理权限。

## 3. 范围
本期包含项目 CRUD、列表选择、成员列表、候选搜索、添加成员、角色调整、移除成员和资源隔离。不包含组织/部门、多租户、邀请链接、owner 转让、归档恢复、自定义 RBAC 和审计。

## 4. 角色与权限
| 操作 | owner | admin | member |
| --- | ---: | ---: | ---: |
| 创建/查看项目 | 允许 | 允许 | 允许 |
| 编辑/删除项目 | 允许 | 禁止 | 禁止 |
| 查看成员 | 允许 | 允许 | 允许 |
| 搜索/添加/改角色/移除 | 允许 | 允许 | 禁止 |
| 使用项目资产 | 允许 | 允许 | 允许 |
约束：每个项目只有一个 owner；owner 不能降级或移除；成员接口不能新增 owner。

## 6. 功能需求
### PRJ-F01 创建项目
- 用户故事：作为用户，我希望创建独立项目空间。
- 前置条件：名称非空且不超过 100 字符，描述可空且不超过 500 字符。
- 主流程：填写 -> 校验全局唯一 -> 创建 -> 创建者成为 owner -> 返回 201。
- 验收标准：重名 409；未登录 401；字段非法 422；成功后列表可见。

### PRJ-F02 查看与选择项目
- 用户故事：作为成员，我希望选择参与项目并设置后续请求上下文。
- 主流程：列表只返回成员项目 -> 选择 -> 保存项目 ID -> 请求发送 X-Project-Id。
- 规则：无选择时自动选择可用项目；无项目进入项目管理页。
- 验收标准：非成员详情 404；删除当前项目后前端清空旧 ID。

### PRJ-F03 编辑项目
- 用户故事：作为 owner，我希望修改名称和描述。
- 规则：仅 owner；名称仍需全局唯一和长度校验。
- 验收标准：owner 合法更新成功；admin/member 403；重名 409 且数据不变。

### PRJ-F04 删除项目
- 用户故事：作为 owner，我希望删除不再使用的项目。
- 规则：成员和关联资产删除需事务一致，失败整体回滚；成功 data=null。
- 验收标准：删除后详情 404、资产不可访问；非 owner 403；当前选择清空。

### PRJ-F05 查看项目成员
- 用户故事：作为成员，我希望查看成员和角色。
- 规则：只返回本项目，owner 保持唯一。
- 验收标准：成员可查；非成员 404；成员数据不串项目。

### PRJ-F06 搜索并添加成员
- 用户故事：作为 owner/admin，我希望搜索已注册用户并加入项目。
- 前置条件：关键词 2 至 50 字符，目标用户未加入。
- 主流程：搜索候选（最多 50 条） -> 选择 admin/member -> 创建关系。
- 规则：不可添加 owner；重复添加 409；用户不存在 404。
- 验收标准：member 403；非法角色 422；成功后成员列表出现。

### PRJ-F07 修改成员角色
- 用户故事：作为 owner/admin，我希望在 admin/member 间调整职责。
- 规则：owner 不可降级；member 无权；目标成员须属于当前项目。
- 验收标准：合法更新成功；owner 目标 409；跨项目成员 404。

### PRJ-F08 移除成员
- 用户故事：作为 owner/admin，我希望回收普通成员访问权。
- 规则：owner 不可移除；移除后目标用户不能访问项目资源。
- 验收标准：member 403；owner 目标 409；成功后关系删除且访问被拒绝。

### PRJ-F09 项目资源隔离
- 用户故事：作为用户，我希望项目资产严格隔离。
- 前置条件：项目请求携带 Token 和 X-Project-Id。
- 主流程：认证 -> 校验成员 -> Repository 按 project_id 查询/变更。
- 规则：不能仅凭资源 ID 跨项目访问；无权优先 404。
- 验收标准：A 用户访问 B 资源 404/权限错误；缺项目头 422；缺 Token 401。

## 7. 非功能要求
后端强制鉴权；跨项目错误不泄露存在性；删除事务可回滚；错误码稳定可断言。

## 8. 当前实现与待确认项
已实现：全局项目名唯一、owner/admin/member、X-Project-Id 隔离、成员跨项目拒绝。
待确认：删除恢复、移除后 Token 失效、admin 是否可移除 admin、报告/流量/性能结果保留期限。
