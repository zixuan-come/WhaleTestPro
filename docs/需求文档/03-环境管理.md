# 环境管理

> PRD v2：按用户功能拆分，供产品确认、Butterfly Agent 评审和测试设计使用。

## 1. 文档信息
| 项目 | 内容 |
| --- | --- |
| 状态 | 评审草案 |
| 目标用户 | 项目成员 |
| 关联模块 | 项目、接口执行、变量渲染 |

## 2. 背景与目标
环境把接口路径与部署地址解耦，并向用例、场景和回归执行提供环境级变量。

## 3. 范围
本期包含环境 CRUD、项目隔离、Base URL、变量维护和执行上下文生成；不包含密文变量、密钥托管、连通性探测和环境复制。

## 4. 角色与权限
项目成员均可查看、创建、更新、删除和使用当前项目环境；请求必须有 Bearer Token、X-Project-Id 和成员关系。

## 6. 功能需求
### ENV-F01 创建环境
- 用户故事：作为成员，我希望保存环境地址。
- 前置条件：name 非空且不超过 100 字符，base_url 非空且不超过 500 字符。
- 主流程：填写 -> 校验项目和字段 -> 保存 -> 返回详情。
- 验收标准：合法请求 201；缺少项目头 422；非成员 404；字段错误 422。

### ENV-F02 查看环境列表和详情
- 用户故事：作为成员，我希望选择并核对执行目标。
- 业务规则：列表和详情只返回当前项目；跨项目 ID 返回 404。
- 验收标准：项目 A 列表不出现 B 环境；已删除 ID 查询 404。

### ENV-F03 更新环境
- 用户故事：作为维护者，我希望修改地址和变量。
- 业务规则：全量更新，后续执行立即使用新值。
- 验收标准：合法更新成功；非法字段 422；跨项目更新 404。

### ENV-F04 删除环境
- 用户故事：作为维护者，我希望删除无效环境。
- 业务规则：删除后 ID 不可查询；当前版本不检查历史任务引用。
- 验收标准：返回 200；再次查询 404；其他项目数据不变。

### ENV-F05 管理环境变量
- 用户故事：作为用例维护者，我希望复用环境级参数。
- 业务规则：variables 为 JSON 对象；数据集同名字段覆盖环境变量；模板支持嵌套字典和数组递归替换。
- 验收标准：变量可用于 URL、Header、Query、JSON Body；缺失变量形成可诊断失败。

### ENV-F06 生成执行上下文
- 用户故事：作为执行器，我希望得到统一 Base URL 和变量上下文。
- 业务规则：完整 URL = base_url 去尾斜杠 + "/" + path 去首斜杠；env_id 为空使用空上下文；无效 env_id 不读取其他项目。
- 验收标准：无重复斜杠；切换项目不会复用旧环境 ID。

## 7. 非功能要求
Repository 必须再次按 project_id 过滤；环境变量及执行证据中的敏感值不得明文输出。

## 8. 当前实现与待确认项
已实现：普通 JSON 变量、项目隔离、前端按项目记忆最近环境。
待确认：名称唯一性、健康检查、删除前引用检查、密文变量。
