# 测试报告

> PRD v2：按用户功能拆分，供产品确认、Butterfly Agent 评审和测试设计使用。

## 1. 文档信息
| 项目 | 内容 |
| --- | --- |
| 状态 | 评审草案 |
| 目标用户 | 项目成员、测试负责人、排障人员 |
| 关联模块 | 用例执行、场景执行、报告仓储 |

## 2. 背景与目标
报告保存执行结果、统计和证据，帮助判断成功率并定位失败原因；报告只能由执行流程生成。

## 3. 范围
本期包含用例/场景报告生成、列表、详情、步骤明细、分页和统计；不包含删除、导出、搜索、筛选、保留策略和手工创建。

## 4. 角色与权限
项目成员可查看当前项目报告；报告生成由执行器内部完成。

## 6. 功能需求
### REPORT-F01 生成用例报告
- 用户故事：作为执行器，我希望每次单用例执行留下记录。
- 规则：一次执行一条报告；保存用例 ID、通过状态、详情和时间。
- 验收标准：单用例执行后当前项目报告数增加 1。

### REPORT-F02 生成场景报告
- 用户故事：作为场景执行器，我希望保存汇总和逐步骤证据。
- 规则：一次执行一条汇总及多条步骤；名称为快照；所有步骤通过才 passed。
- 验收标准：步骤数量和顺序与执行一致。

### REPORT-F03 查看报告列表
- 用户故事：作为成员，我希望按时间查看报告。
- 规则：只返回当前项目；支持 page/page_size；超范围页返回空 items。
- 验收标准：跨项目 ID 404；total 正确。

### REPORT-F04 查看报告详情
- 用户故事：作为排障人员，我希望打开单条报告。
- 规则：详情按项目隔离；不存在或跨项目 404。
- 验收标准：详情包含通过状态、状态码、断言和耗时。

### REPORT-F05 查看步骤明细
- 用户故事：作为排障人员，我希望逐步查看请求和响应。
- 规则：场景步骤按 sequence 升序；敏感 Header/Body/提取值遮罩；响应体最多 64 KiB。
- 验收标准：密码、Token、Cookie 不明文；截断有标记。

### REPORT-F06 分页和统计
- 用户故事：作为负责人，我希望看到全量通过率。
- 规则：page>=1；page_size 1 至 100；total_pages=ceil(total/page_size)，无数据为 0；pass_rate=passed/total，无数据为 0。
- 验收标准：统计基于全部匹配报告；参数非法 422。

## 7. 非功能要求
报告写入与步骤写入保持一致；敏感数据默认脱敏；统计限定项目上下文。

## 8. 当前实现与待确认项
已实现：用例/场景报告、步骤详情、分页统计、前端切换。
当前限制：普通报告不保存完整请求/响应证据。
待确认：导出、保留期限、搜索和筛选。
