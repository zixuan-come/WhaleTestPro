# 回归测试 · 定时任务

2026-10-18 用户确认整合方案后的当前验收需求。本功能位于“回归测试 → 定时任务”；不再保留独立侧栏入口。原 `/schedules` 地址跳转到该 Tab。

## 1. 创建与编辑

- 点击“新建任务”，选择执行环境，再勾选一个或多个测试套件，或手动勾选用例。名称搜索、全选当前结果和预览与立即执行共用。
- 必须明确勾选内容；空选择不等于全量回归。场景流程先加入套件，场景中的步骤保持顺序及变量传递。
- 清单有效后点击“设置执行时间”，填写任务名称，选择每小时/每天/每周/每月或自定义五段 Cron；预览执行时间，可选择创建后启用。
- 定时环境必填；保存的是明确选中的 ID 和环境，执行时使用这些资产的最新配置。多个套件分别执行，不做跨套件去重。
- 保存创建不立即发送下游测试请求；显示平台成功/失败提示，保存期间阻止重复提交。
- 编辑复用相同选择流程，已有名称、环境、目标、频率和启用状态回显；取消编辑不保存。
- 飞书通知复用项目配置，默认不发送，只有已配置且启用时可勾选。

## 2. 列表与报告

- 统计全部、启用中、已停用数量；每行显示名称、易读执行规则、测试内容与环境、启停状态及操作。
- 执行规则默认使用人类可读文字，展开可查看 Cron，时间按调度服务配置时区计算。
- 提供编辑、启停、删除和查看报告。新任务报告使用任务名称，归入“回归测试”，触发来源为“定时执行”，并保留套件/场景/用例的报告层级。
- 查看报告按当前任务名称筛选；同名任务可能一起匹配，历史报告保留当时的名称。旧绑定套件任务仍到套件报告分类查看，不虚构独立调度历史。
- 同步中或失败必须可见；RedBeat/Redis 故障时数据库定义仍保留，由持久化 Outbox 重试同步。

## 3. 调度与安全

- `selection={mode:case|suite, ids:[正整数...]}` 与兼容单套件字段 `suite_id` 互斥；传入已移除的 `tag` 返回 422；ID 去重，最多 1000 项。
- 创建或变更目标时检查所属项目；启用时确认可执行清单。缺失或跨项目目标不执行，不能退化为执行全部用例。
- 定时派发携带任务 ID。Worker 取数据库最新定义；任务已停用、删除时跳过，避免旧消息重新执行旧范围。
- 已删除引用的现有任务仍可直接停用；重新启用须修复目标。删除任务同步删除 RedBeat 条目，历史报告保留。
- 沿用 `schedule.write` 团队权限，UI 名称为“回归定时任务”；查看须项目成员，维护须该权限。回归执行权限与写权限的区分保持。

## 4. 已有任务兼容

- 迁移 `019_schedule_selection` 为主库和影子库增加 nullable `selection` 及默认 false 的 `notify`，保留所有旧名称、Cron、标签、套件和环境，不自动猜测新执行范围。
- 迁移 `020_remove_case_tags` 删除标签列；若发现旧标签规则，先固定为同项目当前匹配的用例清单。没有匹配内容的任务停用；不能回退到执行全部用例。
- 旧绑定套件任务仍可执行绑定套件；没有明确选择或绑定套件的任务拒绝执行，必须编辑后再启用。
- 没有环境的历史任务必须先补充环境才能启用。

## 5. HTTP 接口与验收

定时任务保留 `POST/GET /schedules`、`GET/PUT/DELETE /schedules/{schedule_id}` 五项管理接口。与立即执行共用 `GET /regression/options`、`POST /regression/preview` 和 `POST /regression/run`，没有额外增加路由。移除旧 `POST /regression` 后平台共有 **107 项接口**。

验收覆盖创建/编辑两种选择、空/非法 ID、跨项目、回显、通知开关、启停、删除、同步失败恢复、报告层级与触发来源，以及已停用/删除任务的旧消息保护。需要等待 Cron 到点的时钟验证与使用真实条目派发到 Worker 的验证分别记录。
