# 流量录制与回放

> PRD v2：按用户功能拆分，供产品确认、Butterfly Agent 评审和测试设计使用。

## 1. 文档信息
| 项目 | 内容 |
| --- | --- |
| 状态 | 评审草案 |
| 目标用户 | 项目成员、排障人员 |
| 关联模块 | HTTP 中间件、Celery、环境、影子库、Diff |

## 2. 背景与目标
异步保存具备可信项目归属的 HTTP 请求与响应，把历史请求回放到指定环境并比较差异。内部示例订单回放使用服务端签名的影子凭证，不允许普通客户端把平台管理接口切到影子库。

## 3. 范围
本期包含录制、异步落库、嵌套对象与数组脱敏、查询、环境回放、受信任的示例订单影子回放、响应 Diff 和结果查看；不包含录制开关、非 JSON Body 解析和回放取消。

## 4. 角色与权限
项目成员可查看和回放当前项目记录；健康、指标、文档、静态、认证、团队、项目及流量管理路径不录制。

## 6. 功能需求
### TRAFFIC-F01 录制真实 HTTP 流量
- 用户故事：作为维护者，我希望保存业务请求证据。
- 主流程：读取并恢复请求体 -> 调用下游 -> 读取并重建响应 -> 投递录制事件。
- 规则：记录 method、path、请求头、JSON Body、响应状态/Body、project_id、时间；归属仅来自服务端鉴权项目上下文，公开 Mock 使用匹配规则归属。无上下文不录制，不默认使用项目 1。示例订单需提供有效用户和项目才能录制。
- 验收标准：录制失败不改变原业务响应；请求体和响应体仍完整可读；每次投递失败累加 `whale_traffic_record_enqueue_failures_total`，错误日志按 60 秒限频且不记录请求头、Body 或异常原文。

### TRAFFIC-F02 异步落库
- 用户故事：作为调用方，我希望录制不拖慢业务请求。
- 规则：中间件入队前脱敏请求及响应（包括嵌套数组）；Worker 防御性脱敏后落库，丢弃非项目管理路径的历史积压消息；投递/序列化失败不阻断主流程。
- 验收标准：消息不可用时业务仍原样返回；敏感字段落库为 ***。

### TRAFFIC-F03 查询录制记录
- 用户故事：作为成员，我希望查看最近流量。
- 规则：列表默认最多 100 条；列表和详情按项目隔离；历史误归属的团队/认证等非项目记录不可从列表、详情或回放读取，原始数据保留供管理员审计。
- 验收标准：A 不得查询/查看 B 记录；不存在返回 404。

### TRAFFIC-F04 选择环境回放
- 用户故事：作为测试人员，我希望把历史请求发到目标环境。
- 规则：无 env_id 使用 http://127.0.0.1:8000；指定环境使用当前项目 Base URL；无效或跨项目环境返回 404，不回退本机；不转发历史 Host、Content-Length 或脱敏鉴权头。
- 验收标准：目标 URL 拼接正确；跨项目环境不可读取。

### TRAFFIC-F05 影子库回放
- 用户故事：作为测试人员，我希望回放写请求不污染主库。
- 规则：内部回放只允许示例业务 /demo/orders；X-Shadow: 1 必须配合服务端生成的短期 X-Shadow-Authorization，绑定方法与路径。平台认证、团队、项目、调度等接口不允许影子切换；外部目标绝不接收内部签名凭证。
- 验收标准：普通或过期影子请求返回 403；合法内部回放只操作影子订单表，不改变用户身份；外部系统仅收到影子提示头，隔离能力取决于该系统实现。

### TRAFFIC-F06 响应 Diff
- 用户故事：作为排障人员，我希望识别真实响应变化。
- 规则：支持 ignore、type、regex、range；默认 id 只校验 int，时间字段只校验 str，token 忽略；未配置字段精确比较，对象检查新增/缺失，数组检查长度和逐项差异。
- 验收标准：动态 id 类型一致不判差异；差异返回具体 path 和原因。

### TRAFFIC-F07 查看回放结果
- 用户故事：作为成员，我希望看到状态码、响应体和差异明细。
- 规则：结果含录制/回放状态码、响应体、通过状态、差异列表；field_rules 可覆盖默认规则。
- 验收标准：前端展示回放状态、状态码对比和 Diff。

## 7. 非功能要求
录制故障隔离主业务；敏感字段默认脱敏；查询/回放按项目授权；Prometheus 可基于录制失败计数器增量配置告警。

## 8. 当前实现与待确认项
已实现：异步录制、脱敏、环境回放、影子库、Diff，以及录制投递失败的 Prometheus 计数和限频日志。
当前限制：非 JSON Body 保存为 null；内部影子回放仅支持示例订单而非管理接口；需由部署环境为失败计数器配置具体告警阈值；前端暂不输入环境和规则。
待确认：录制开关、保留期限、批量回放和规则扩展。
