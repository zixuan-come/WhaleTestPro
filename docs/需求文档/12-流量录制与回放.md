# 流量录制与回放

> PRD v2：按用户功能拆分，供产品确认、Butterfly Agent 评审和测试设计使用。

## 1. 文档信息
| 项目 | 内容 |
| --- | --- |
| 状态 | 评审草案 |
| 目标用户 | 项目成员、排障人员 |
| 关联模块 | HTTP 中间件、Celery、环境、影子库、Diff |

## 2. 背景与目标
异步保存真实 HTTP 请求与响应，把历史请求回放到指定环境；写操作通过 X-Shadow: 1 路由到影子库，再比较录制与回放响应。

## 3. 范围
本期包含录制、异步落库、查询、环境回放、影子库隔离、响应 Diff 和结果查看；不包含录制开关、完整数组脱敏、非 JSON Body 解析和回放取消。

## 4. 角色与权限
项目成员可查看和回放当前项目记录；健康、指标、文档、静态和流量管理路径不录制。

## 6. 功能需求
### TRAFFIC-F01 录制真实 HTTP 流量
- 用户故事：作为维护者，我希望保存业务请求证据。
- 主流程：读取并恢复请求体 -> 调用下游 -> 读取并重建响应 -> 投递录制事件。
- 规则：记录 method、path、请求头、JSON Body、响应状态/Body、project_id、时间；项目 ID 优先 X-Project-Id，Mock 取 URL 值，否则回退默认项目 1。
- 验收标准：录制失败不改变原业务响应；请求体和响应体仍完整可读。

### TRAFFIC-F02 异步落库
- 用户故事：作为调用方，我希望录制不拖慢业务请求。
- 规则：中间件只投递 Celery；Worker 脱敏并落库；投递/序列化失败不阻断主流程。
- 验收标准：消息不可用时业务仍原样返回；敏感字段落库为 ***。

### TRAFFIC-F03 查询录制记录
- 用户故事：作为成员，我希望查看最近流量。
- 规则：列表默认最多 100 条；列表和详情按项目隔离。
- 验收标准：A 不得查询/查看 B 记录；不存在返回 404。

### TRAFFIC-F04 选择环境回放
- 用户故事：作为测试人员，我希望把历史请求发到目标环境。
- 规则：无 env_id 使用 http://127.0.0.1:8000；指定环境使用当前项目 Base URL；无效环境回退本机；不转发历史 Host、Content-Length 或脱敏鉴权头。
- 验收标准：目标 URL 拼接正确；跨项目环境不可读取。

### TRAFFIC-F05 影子库回放
- 用户故事：作为测试人员，我希望回放写请求不污染主库。
- 规则：回放必须带 X-Shadow: 1；平台 RoutingSession 将 shadow 操作路由到 whale_test_pro_shadow。
- 验收标准：平台自身写操作进入影子库；外部系统配合不由平台保证。

### TRAFFIC-F06 响应 Diff
- 用户故事：作为排障人员，我希望识别真实响应变化。
- 规则：支持 ignore、type、regex、range；默认 id 只校验 int，时间字段只校验 str，token 忽略；未配置字段精确比较，对象检查新增/缺失，数组检查长度和逐项差异。
- 验收标准：动态 id 类型一致不判差异；差异返回具体 path 和原因。

### TRAFFIC-F07 查看回放结果
- 用户故事：作为成员，我希望看到状态码、响应体和差异明细。
- 规则：结果含录制/回放状态码、响应体、通过状态、差异列表；field_rules 可覆盖默认规则。
- 验收标准：前端展示回放状态、状态码对比和 Diff。

## 7. 非功能要求
录制故障隔离主业务；敏感字段默认脱敏；查询/回放按项目授权。

## 8. 当前实现与待确认项
已实现：异步录制、脱敏、环境回放、影子库、Diff。
当前限制：非 JSON Body 保存为 null；数组对象脱敏不完整；录制失败无告警；前端暂不输入环境和规则。
待确认：录制开关、保留期限、批量回放和规则扩展。
