## 3. 全局约定
- 普通业务成功响应使用 code/message/data，code=0。
- 失败响应 Body code 与 HTTP 状态一致。
- 除公开端点外需要 Authorization: Bearer Token。
- 项目内资源需要 X-Project-Id 并校验成员关系。
- Mock、Prometheus、Swagger、静态文件等特殊协议不强制业务信封。

## 4. 状态定义
- 已实现：代码和接口已提供，可进入测试。
- 当前限制：现有设计边界或已知缺口，不按缺陷判定，除非行为偏离文档。
- 待确认/待规划：不进入当前版本验收。
